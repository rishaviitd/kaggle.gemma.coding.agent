Time, calls, and reported inference tokens

How to read this

Duration comes from the final harness result. Budgeted calls, raw tool attempts, and model calls differ. Token totals use measured turns, including ATIF sidecars where available, and include repeated prompt context. Turn coverage shows how much of the trace has token data; unmeasured subagent turns remain excluded.
